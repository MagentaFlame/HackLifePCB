Hello!
This is a spin-off of the Starbie starter PCB project for Half Life.
I didn't have much experience, so I started off going step-by-step. However, after gaining some confidence, I made the following changes:
- added a battery + switch
- changed the PCB base layer design to be the mastery symbol from League of Legends but trophy-like due to the battery size

So now, when the switch is flipped on, I can play with my very own poro! Ahead of the LOL World Championships, I hope I can create some fun things that will embody my excitement!
